# xmetai-datakit
雄安气象人工智能创新研究院 - DataKit 数据工具箱

项目概述
xmet-datakit 是 XMetAI 气象大模型体系配套的专用数据处理与质控工具箱，专为气象预报、次季节预测、集合预报等场景打造。聚焦气象多维时序数据的标准化下载、维护更新、格式转换、预处理加工、质量控制等，为气象 AI 模型 xmetai-core 提供统一、稳定、可复用的数据能力，系统解决气象数据分散、异构、异常数据、格式复杂等问题。

核心模块计划：
1. 数据下载与维护模块（Data Downloader）
2. 数据处理模块（Data Processor）
3. 气象数据质控模块（Quality Control）
4. 其他
