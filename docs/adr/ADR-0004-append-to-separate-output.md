# ADR-0004：时间追加写入独立产物

状态：Accepted

## 上下文与目标

用户确认 A 追加到 B 应生成时间顺序为 BA 的独立 C。不能在读取 B 时覆盖重建 B，也不应依赖一次加载完整数据；追加内部应有校验。

## 决策

- append_zarr(source=A, target=B, destination=C, spec=combined_spec)，返回 full ValidationReport，release_passed 决定成功。
- C 必须不存在且与所有输入路径隔离。删除原地追加语义，不提供 overwrite 或 write_options。
- 检查 A、B 的时间顺序、变量元数据及静态数组兼容性；合并后的时间轴和布局须匹配最终契约。
- 文件复制 B 后逐完整时间片加载、写入 A，保留 B 的存储编码、压缩和分块，区分原生 datetime 与 CF 时间编码。
- C 的身份及版本采用最终契约；关闭输入后对 C 执行 full 校验，报告可另存 .yaml。调用方提供最终发布证据和外部附件。
- 输入不可在操作期间变动。失败输出保留供检查，不自动替换 B。

## 约束 & 禁止改动清单

不修改输入，不重算 mean/std/mask，不执行单位转换，不更改质量检查规则。不新增依赖，不一次加载完整 BA，不宣称固定字节内存预算。

## 验收标准

验证 C 为 B+A、A/B 字节不变、逐帧写入、原生/CF 时间编码、完整输出校验，以及路径重叠、已有目标、时间冲突、错误契约、静态数组或变量元数据不兼容时拒绝。写入失败不影响输入；最终数值校验失败不能返回成功。Python 接口显式接收 destination 和最终产物 spec，调用方按 release_passed 判断成功。

## 回滚策略

回退本次接口和调用方变更，不覆盖或恢复任何输入数据；输出由调用方另行管理。

## 风险与取舍

需要完整 BA 的额外磁盘空间，单个时间片及静态附件仍须能放入内存。复制与写入非原子事务，不支持输入并发修改，异常可能留下部分 C。保留 B 的存储编码意味着最终契约须与该编码兼容，不能静默迁移格式或分块。接口为显式兼容性变更，旧调用方须提供新参数并处理报告。
