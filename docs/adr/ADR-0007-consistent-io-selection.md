# ADR-0007：统一 IO 选择语义与参数校验

## 状态

Accepted

## 上下文与目标

read 与 iter_datasets 在标量选择、空结果和缺失标签处理上存在差异，
部分自定义格式写出分支会静默忽略未知参数。
本轮目标为统一选择语义、统一空结果策略、拒绝无效参数。

## 决策

- 标量选择与单元素列表等价，整体读取和逐文件迭代均保留长度为 1 的维度。
- 标量和列表中的时间字符串按精确标签解释；日期字符串表示当天 00:00，
  不隐式匹配整天。时间范围显式使用 slice。
- 整体空结果统一报错，不因自动发现或显式 records 而改变。
  迭代可跳过不匹配的分区，完整消费后没有结果则报错。
- 请求标签必须全部满足。read 对缺失标签报错；迭代可先产出匹配分区，
  完整消费后对未覆盖标签报错。提前停止不代表完整请求已验证。
- IO 消费通用参数，NetCDF、Zarr、GRIB 原生参数交给后端校验。
  NumPy、文本等自定义分支拒绝未识别参数，不维护全格式参数白名单。

## 约束 & 禁止改动清单

- 不修改 YAML 字段、单位换算、科学加工和评估指标。
- 不调整 FileRecord 不可变性、配置解析架构或其他独立议题。
- 保持惰性读取，不为检查标签而加载完整数据数组。
- 保持资源关闭、源路径保护和安全写出行为。
- 不新增第三方依赖、兼容模式或测试文件。
- 修改现有测试及必要调用方，不自动提交 Git。

## 验收标准

- read 与 iter_datasets 对相同标量选择保留一致维度。
- 时间标量与单元素列表精确匹配结果一致，范围使用切片。
- 自动发现和显式记录路径均拒绝整体空结果。
- 部分请求标签缺失时，整体读取及完整迭代均报错。
- 标签可由不同分区分别覆盖，不要求每个文件包含全部标签。
- 自定义格式收到未知参数时报错，不发布输出或替换原目标。
- 错误后正确释放句柄和源路径保护。
- IO、数据集构建和 evaluation 的相关现有回归测试通过。

## 回滚策略

按选择行为统一、参数校验两部分组织改动。出现非预期结果或资源退化时，
恢复对应部分；不迁移数据文件或 YAML 格式，不撤销工作区已有修改。

## 风险与取舍

依赖标量自动删维度的调用方需要显式压缩；依赖日期字符串匹配整天的调用方需使用切片。
原先接受空结果、部分标签或忽略未知参数的流程将收到错误。
迭代可能在产出部分数据后才发现请求缺失，完整验收必须消费至结束。
原生后端的错误类型与文案可能不同，本轮不新增统一异常体系。
